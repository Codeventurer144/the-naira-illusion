Data and model rules

Methodology

The dashboard uses the same calculation engine on every page. Missing historical deposit rates are left missing rather than estimated.

01

Savings benchmark

Uses the annualised CBN savings rate and compounds it monthly using the published rate for the period.

02

Fixed deposits

Locks the selected tenor rate at the start of each term, accrues simple interest, then rolls the balance at maturity using the next available rate.

03

Purchasing power

Adjusts the account balance using NBS headline All Items CPI so the result is expressed in the value of naira in the selected starting month.

04

US dollar value

Converts the simulated naira balance using CBN monthly official/reference NGN-per-USD rates. It does not use the parallel market.

Primary sources

CBN and NBS historical series

Money-market deposit benchmarks and official/reference exchange rates come from the Central Bank of Nigeria. Inflation uses the National Bureau of Statistics headline CPI series on the pre-2025 basis for this 2014–2024 historical module.
